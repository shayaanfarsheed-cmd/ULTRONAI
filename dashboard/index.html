LEARNING SYSTEM / CORE PROCESS

How ULTRON learns mathematics

ULTRON improves through verified examples, supervised learning, independent evaluation and targeted practice—not by assuming that lower training loss means better mathematical ability.

LEARNING-FIRST
THE IMPROVEMENT CYCLE

Learn → test → diagnose → improve

Each candidate model must demonstrate measurable improvement on problems it has not trained on. If it regresses, the previous approved checkpoint is retained.

01GenerateCreate new math problems internally.
02VerifyCheck answers independently before use.
03LearnTrain on versioned supervised examples.
04EvaluateTest on held-out problems by topic.
05ImproveTarget weaknesses and compare checkpoints.
DATA QUALITY

Verified learning material

  • Problems are generated by ULTRON's own deterministic data generator.
  • An independent verifier checks answers before examples enter training.
  • Datasets receive versions and reproducible seeds.
  • Training, validation and frozen test examples remain separated.
GENERATOR + VERIFIER EXIST
MEASURED ABILITY

Evidence of learning

  • Exact-answer accuracy by topic and difficulty.
  • Training loss and validation loss reported separately.
  • Held-out tests detect memorisation and regressions.
  • Failed examples are grouped into actionable error categories.
EVALUATION HARNESS NEXT
CONTROLLED IMPROVEMENT

Candidate promotion rules

NO AUTO-PROMOTION
1. Compare

Measure the candidate against the currently approved checkpoint on the same frozen evaluation set.

2. Check regressions

Reject candidates that lose previously demonstrated skills beyond agreed thresholds.

3. Promote or roll back

Keep the previous valid checkpoint unless the candidate passes every acceptance gate.
